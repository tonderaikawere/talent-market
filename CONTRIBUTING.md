# Contributing Guidelines

Thank you for your interest in contributing to Talent Market!

## How to Contribute
1. Fork the repository and create a new branch.
2. Ensure you have Node.js installed.
3. Keep changes clean and follow standard JavaScript styling.
4. Open a pull request with a descriptive summary of your changes.

## Code Standards
- Use ES6+ syntax.
- Add comments where appropriate.
- Test your changes locally before opening a pull request.
